# AI Coach 篡改猴探针脚本

## 文件

- `aicc-probe.user.js` — 通用网页结构探针（v0.1）

## 安装步骤

### 1. 装篡改猴扩展（如已装跳过）

- Chrome / Edge 商店搜「Tampermonkey」并启用
- 校内 OJ 是 HTTP + IP，需要确认篡改猴**不限制 HTTP 站点**（默认开）

### 2. 安装本脚本

**方法 A · 拖拽**

把 `aicc-probe.user.js` 文件拖到浏览器窗口 → 篡改猴会弹「安装」对话框 → 点「安装」

**方法 B · 复制粘贴**

1. 点击篡改猴图标 → 「管理面板」
2. 「+」新建脚本 → 删除默认内容
3. 把 `aicc-probe.user.js` 全部内容粘进去 → Ctrl+S 保存

### 3. 使用流程

1. 访问任意题目页面（头歌 / 校内 OJ / 其他）
2. **页面右下角会出现一个橙色 🔍 浮动按钮**
3. 点击 → 弹出黑色面板，显示页面分析：
   - 标题候选
   - 文本容器 top 10（按文字量排序）
   - 图片
   - 代码块
   - 编辑器（CodeMirror / Monaco / Ace）
   - Tabs
   - 操作按钮（提交/评测）
   - iframes
4. **鼠标 hover 任意行** → 在原页面高亮该元素 + 滚动到位置（确认选择器对不对）
5. 顶部按钮：
   - **📋 复制 JSON** → 把分析结果复制到剪贴板，粘给我
   - **📄 复制 HTML** → 复制整个页面的 outerHTML 给我（备用）
   - **⬇ 下载** → 同时下载 JSON + HTML

## 我需要的数据

针对**头歌** + **校内 OJ** 各做以下：

1. 打开一道**有图片**的题目（图越多越好，至少 1 张）
2. 滚动到底确保所有内容（题面 / 样例 / 测试集）都加载
3. 点 🔍 → 复制 JSON 给我
4. 如果可能，**也复制 HTML**（很大，可以下载文件给我）

## 已匹配站点

`@match` 当前为 `*://*/*` + `http://10.11.219.21/*`，所有页面都会注入按钮。

如不喜欢全局注入，可改成只匹配特定站点（编辑脚本头部 `@match`）：

```
@match https://www.educoder.net/*
@match http://10.11.219.21/*
```
