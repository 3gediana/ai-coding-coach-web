## 项目概述

**面向算法竞赛学习者的多 Agent 编程教练 Web 应用**。不是「带聊天框的 IDE」，而是多个 AI Agent 围绕「学」这件事自主感知、自主决策、自主行动——用户从打开 app 到关掉，13 个 Agent 在背后协作，其中 DailyPlan(3子) + Feynman(2子) 会编排协作，2 个本地纯逻辑 Agent (Selector / AstDiff) 不调 LLM。

## 2. 核心机制

### 2.1 入口点

**What it does**: React 应用单页入口，负责主题初始化、e2e 测试数据注入、onboarding 触发。

**Files**:
- `src/main.tsx` — React DOM 挂载、主题初始化、dev 模式下 store 挂到 window
- `src/App.tsx` — 主布局渲染、onboarding effect、每日计划触发、导入接收初始化

**Flow**:
```
main.tsx → ReactDOM.createRoot → App.tsx → 渲染完整 UI
                                     ↓
                              useEffect: seed=demo → loadDemoSeed()
                              useEffect: 首次配AI → startOnboarding()
                              useEffect: 每日 → requestDailyPlan()
                              useEffect: SSE → startImportReceiver()
```

---

### 2.2 AI 客户端 (AIClient)

**What it does**: 统一封装所有 AI LLM 调用，支持 OpenAI/Ollama 双协议、流式 SSE、JSON 解析、重试退避、CORS 代理。

**Files**:
- `src/core/ai/client.ts` — 主实现（AIClient 类，100+ 方法）
- `src/lib/presets.ts` — AI 服务商预设（DeepSeek/MiniMax/OpenAI/Qwen/等）
- `src/lib/ollama.ts` — Ollama 本地模型管理

**Flow**:
```
AIClient.chat / chatStream / chatJson / chatJsonStream
         ↓
    buildProxyUrl() → /ai-proxy/<encoded> (dev) 或直连 (prod)
         ↓
    buildBody() → OpenAI 格式 或 Ollama 原生格式
         ↓
    fetchWithRetry() → 429/5xx 指数退避重试
         ↓
    流式解析 → NDJSON (Ollama) 或 SSE (OpenAI)
         ↓
    parseJsonLoose() → 自动补全截断 JSON
```

**Dependencies**: `fetch`, `AbortSignal`, Vite proxy middleware

### 2.3 Coach 类（13 个 Agent 的家）

**What it does**: 将 AI 能力封装为结构化方法，涵盖代码批注、错题总结、卡住引导、hack case 生成、每日复习、费曼教学等 13 个 Agent。

**Files**:
- `src/core/analyzer.ts` — Coach 类主实现
- `src/core/ai/prompts.ts` — 15+ 个提示词 builder
- `src/core/coach/router.ts` — 意图分类路由（7 种意图）

**主要 Agent 方法**:
| Agent | 方法 | 路由 |
|-------|------|------|
| 代码批注 | `analyzeCode()` | 本地/云端 |
| 错题总结 | `summarizeMistake()` | 云端 |
| 卡住引导 | `getStuckHint()` | 本地优先 |
| Hack Case | `generateHackCase()` | 云端 |
| 题意速读 | `generateProblemOverview()` | 云端 |
| AC 复盘 | `generateAcReview()` | 云端 |
| 每日复习 | `pickDailyReview()` | 本地（纯逻辑） |
| 学习诊断 | `generateLearningDiagnosis()` | 云端 |
| 题目筛选 | `pickPlanCandidates()` | 本地（纯逻辑） |
| 计划编排 | `generatePlanOrchestration()` | 云端 |
| 费曼学生 | `generateFeynmanStudentReply()` | 云端 |
| 费曼评委 | `generateFeynmanEvaluation()` | 云端 |

**Dependents**: `store.ts` (requestDailyPlan, requestAcReview 等), 各种 Card 组件

### 2.4 学习引擎（推荐系统）

**What it does**: 基于错题本和学习记录，生成推荐卡片、计算掌握度、间隔重复调度。

**Files**:
- `src/core/recommend.ts` — `buildLearningEngine()`, `pickDailyReview()`, `pickPlanCandidates()`
- `src/core/profile.ts` — `aggregateStudentProfile()` 学生画像聚合
- `src/core/utils.ts` — `masteryOf()`, `aggregateMastery()`, `buildLearnerProfile()`

**Flow**:
```
buildLearningEngine(mistakes, problems, sessions, bank)
         ↓
    buildOverview() → 进度概览（错题率/本周活跃/top错误类型）
         ↓
    buildCards() → 生成 1-4 张推荐卡片
        - review-mistakes: 未复习错题
        - new-similar: 同主题新题
        - level-up: 难度递增
        - concept-recall: 错点回顾
        - first-step: 入门题
        - browse-mistakes: 浏览错题本

pickDailyReview() → 间隔重复打分（未复习/已复习1次/已复习多次）
```

### 2.6 FastLane 本地推理

**What it does**: 本地 Ollama 模型处理高频实时任务（批注/归因/嗅探），降低云端消耗。

**Files**:
- `src/core/ai/router.ts` — 路由决策（pickRoute）
- `src/lib/ollama.ts` — Ollama 模型管理
- `src/lib/offlineMode.ts` — 离线模式检测

**路由规则**:
- `parse` / `summarize` → 永远云端
- `stuck` / `explain` → 永远本地
- `analyze` → 代码 <1500字 + 简单题 → 本地，否则云端
- `ask` → 短问题 → 本地

## 5. 跨领域关切

### 日志

- Agent 行动日志通过 `recordAgentTrace()` 写入 store，UI 实时渲染
- `console.debug` 用于开发模式下路由决策日志

### 错误处理

- AI 调用失败 → 指数退避重试（429/5xx）
- FastLane 不可用 → 自动回落到云端
- 离线模式 → 强制使用 FastLane（若可用）

### 安全

- API Key 存储在 localStorage（前端）
- Vite proxy 中间件做 CORS 绕过
- 题面抓取白名单仅限指定 OJ 域名

### 测试

- Playwright E2E 测试覆盖冒烟/功能/AI行为
- `/?seed=demo` 注入演示数据
- dev 模式 store 挂到 window 供 Playwright 注入

## 7. 关键流程图

### DailyPlan 三步编排

```
requestDailyPlan()
       ↓
[1/3] generateLearningDiagnosis() — 云端 LLM
       ↓ 诊断失败则中止
[2/3] pickPlanCandidates() — 本地纯逻辑（无 LLM）
       ↓ 候选为空则中止
[3/3] generatePlanOrchestration() — 云端 LLM
       ↓
渲染 DailyPlanCard
```

### FastLane 嗅探流程

```
RuntimePane: 用户运行代码
       ↓ exitCode ≠ 0
diagnoseRuntimeError() — FastLane (<500ms)
       ↓ 输出 hint
appendCoachHint() — 写入 coachHintsByScope
       ↓
Editor: 右上角角标显示
```

### 费曼反向教学

```
用户开启费曼模式
       ↓
generateFeynmanStudentReply() — AI 装学生提问
       ↓ N 轮对话
用户结束讲解
       ↓
generateFeynmanEvaluation() — AI 评委评分
       ↓
渲染评分报告（clarity/logic/accuracy）
```
